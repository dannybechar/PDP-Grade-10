# B3.1.2 — Keyboard Events

This 45-minute lesson develops character keys, coded keys, and keyboard callbacks.

## Materials

- Revised presentation in `teacher/`.
- Three runnable BlueJ projects in `examples/`: starter, model, and complete.

## Success criteria

Students can trace the input → state update → rendered result pathway, compile the Java-mode Processing sketch, and explain why the relevant fields must persist between method calls.
