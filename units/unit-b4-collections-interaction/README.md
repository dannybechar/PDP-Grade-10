# Unit B4 — Collections & Interaction

Unit B4 develops fixed-size arrays, parallel properties, collection checks, per-frame updates, active-count removal, and capacity-guarded addition.

## Contents

- [`01-storing-many-elements`](01-storing-many-elements): Storing Many Elements in an Array — array allocation, indexing, length, and loop-based fill/read.
- [`02-parallel-arrays`](02-parallel-arrays): Parallel Arrays — coordinating multiple properties through one shared index.
- [`03-checking-collection-behaviour`](03-checking-collection-behaviour): Checking Collection Behaviour — accumulators and conditions while iterating over arrays.
- [`04-per-frame-movement`](04-per-frame-movement): Per-Frame Movement — mutating parallel-array positions using per-element velocities.
- [`05-lifespan-removal`](05-lifespan-removal): Lifespan and Removal — active counts, backward iteration, and swap-and-pop removal.
- [`06-addition-synthesis`](06-addition-synthesis): Addition and Synthesis — capacity-guarded addition combined with movement and removal.

Each lesson includes a revised seven-slide presentation with a 45-minute teacher script and three synchronized runnable BlueJ projects.
