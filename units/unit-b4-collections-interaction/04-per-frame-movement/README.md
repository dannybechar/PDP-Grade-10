# B4.2.1 — Per-Frame Movement

This 45-minute lesson develops mutating parallel-array positions using per-element velocities.

## Materials

- Revised presentation in `teacher/`.
- Starter, model, and complete BlueJ projects in `examples/`.

## Success criteria

Students can trace indices and state changes, preserve the lesson invariant, compile the Java-mode Processing sketch, and explain the visible result.
