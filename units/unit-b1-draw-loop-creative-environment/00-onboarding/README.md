# Onboarding — First 45 Minutes

This package is the first class meeting for Unit B1. Its purpose is to leave every student with a working creative-coding environment and one successful edit–compile–run cycle.

## Package map

| Audience | Resource | Purpose |
|---|---|---|
| Teacher | [`teacher/Unit_B_Course_Setup_First_45_Minutes.pptx`](teacher/Unit_B_Course_Setup_First_45_Minutes.pptx) | Projected walkthrough with speaker notes and troubleshooting appendix |
| Teacher | [`teacher/TEACHER_RUNBOOK.md`](teacher/TEACHER_RUNBOOK.md) | Preflight, timings, checkpoints, and recovery decisions |
| Student | [`student/SETUP_CHECKLIST.md`](student/SETUP_CHECKLIST.md) | Single-page sequence students can follow and check off |
| Student | [`examples/FirstSketch_Starter`](examples/FirstSketch_Starter) | Initial working program with a 60-pixel circle |
| Teacher | [`examples/FirstSketch_Complete`](examples/FirstSketch_Complete) | Verified result after changing the circle to 120 pixels |

## Learning outcome

By the end of the session, students can explain and demonstrate this cycle:

1. Edit a source-code value.
2. Compile the class.
3. Run `main`.
4. Observe a visible change.

## Verification status

- **Windows:** physically verified on Windows 11 x64 with BlueJ 6.0.0 and Processing 4.5.6.
- **macOS:** instructions prepared from official documentation; physical-device verification is still pending.

## Important version rule

This package pins BlueJ 6.0.0 and Processing 4.5.6 because that exact combination was tested. If either version changes, the teacher must rerun the preflight and update the JAR filename shown in the materials.
