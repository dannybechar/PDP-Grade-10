PROJECT TITLE: CanvasSketch Starter

PURPOSE:
Provide the complete BlueJ/PApplet wrapper used at the start of B1.1.1.

REQUIREMENTS:
BlueJ 6.0.0 with the Processing 4.5.6 core library loaded.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click CanvasSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
A blank 400 x 400 sketch window opens.

STUDENT TASK:
Keep this working wrapper. During the lesson, change the canvas to 500 x 300
and add the requested ellipse() calls inside setup().
