PROJECT TITLE: CanvasSketch Single Circle

PURPOSE:
Demonstrate how ellipse(x, y, width, height) places one circle.

REQUIREMENTS:
BlueJ 6.0.0 with the Processing 4.5.6 core library loaded.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click CanvasSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
A 400 x 400 sketch window opens.
A 40 x 40 circle is centered at (100, 150).

TEACHING CHECK:
The first two ellipse() values are the center coordinates in the default mode.
The last two values are the width and height in pixels.
