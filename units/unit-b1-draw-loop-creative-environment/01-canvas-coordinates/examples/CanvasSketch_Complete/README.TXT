PROJECT TITLE: CanvasSketch Complete

PURPOSE:
Provide the verified final construction target for B1.1.1.

REQUIREMENTS:
BlueJ 6.0.0 with the Processing 4.5.6 core library loaded.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click CanvasSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
A 500 x 300 sketch window opens.
Two 50 x 50 circles appear.
Their centers are (100, 75) and (400, 225).

TEACHER USE:
Keep this project hidden until students have attempted the construction task.
Use it for recovery or comparison, not as the starting file.
