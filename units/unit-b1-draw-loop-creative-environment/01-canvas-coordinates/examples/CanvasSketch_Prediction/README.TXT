PROJECT TITLE: CanvasSketch Prediction

PURPOSE:
Support the predict-before-run formative check in B1.1.1.

REQUIREMENTS:
BlueJ 6.0.0 with the Processing 4.5.6 core library loaded.

BEFORE RUNNING:
Sketch a 300 x 300 canvas on paper.
Mark the predicted center of each circle.
Decide which circle is closest to the top and which is closest to the bottom.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click CanvasSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
Three 30 x 30 circles appear.
Their centers are (50, 50), (250, 50), and (150, 250).
The first two tie for closest to the top. The third is closest to the bottom.
