PROJECT TITLE: ShapesSketch Starter

PURPOSE:
Provide the complete BlueJ/PApplet wrapper used at the start of B1.2.1.

REQUIREMENTS:
BlueJ 6.0.0 with the Processing 4.5.6 core library loaded.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click ShapesSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
A blank light-gray 400 x 300 sketch window opens.

STUDENT TASK:
Keep this working wrapper. Add and test the geometry calls at each checkpoint.
