PROJECT TITLE: ShapesSketch Predict

PURPOSE:
Provide the mixed-primitives formative check from B1.2.1.

REQUIREMENTS:
BlueJ 6.0.0 with the Processing 4.5.6 core library loaded.

HOW TO RUN:
1. Predict the full scene on paper before opening the project.
2. Open this folder as a BlueJ project.
3. Click Compile.
4. Right-click ShapesSketch.
5. Run void main(String[] args).
6. Accept the argument and click OK.

EXPECTED RESULT:
A rectangle begins at (40, 40), an ellipse is centered at (240, 80), and a
horizontal line connects (40, 240) to (280, 240).
