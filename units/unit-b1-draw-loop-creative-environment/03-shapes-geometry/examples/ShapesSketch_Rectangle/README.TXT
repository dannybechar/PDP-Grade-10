PROJECT TITLE: ShapesSketch Rectangle

PURPOSE:
Provide the verified program for B1.2.1 Checkpoint 1.

REQUIREMENTS:
BlueJ 6.0.0 with the Processing 4.5.6 core library loaded.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click ShapesSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
A rectangle starts at (100, 100), extends 150 pixels right, and extends
80 pixels down.

KEY IDEA:
rect() uses its first pair as the upper-left corner by default.
