PROJECT TITLE: ShapesSketch Line

PURPOSE:
Provide the verified program for B1.2.1 Checkpoint 2.

REQUIREMENTS:
BlueJ 6.0.0 with the Processing 4.5.6 core library loaded.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click ShapesSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
A line connects (60, 260) to (260, 60), rising toward the right.

KEY IDEA:
line() uses two endpoint pairs, not a position plus width and height.
