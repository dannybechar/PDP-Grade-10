PROJECT TITLE: ShapesSketch Compare

PURPOSE:
Compare the default reference points used by rect() and ellipse().

REQUIREMENTS:
BlueJ 6.0.0 with the Processing 4.5.6 core library loaded.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click ShapesSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
Both shapes use (150, 150, 60, 60), but the rectangle starts at the shared
point while the ellipse is centered on it.

KEY IDEA:
The function name determines how the coordinate pair is interpreted.
