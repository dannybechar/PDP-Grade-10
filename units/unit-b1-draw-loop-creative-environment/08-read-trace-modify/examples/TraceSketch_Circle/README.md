# TraceSketch_Circle

First unfamiliar program from the lesson.

Expected result: a mid-gray circle moves right by 4 pixels and grows by 1 pixel in diameter per `draw()` call. `background(255)` clears the previous frame, so there is no trail.

First visible values: `x = 24`, `d = 16`. After three calls: `x = 32`, `d = 18`.
