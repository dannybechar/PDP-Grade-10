PROJECT TITLE: SetupDrawSketch Starter

PURPOSE:
Provide the complete BlueJ/PApplet wrapper used at the start of B1.1.2.

REQUIREMENTS:
BlueJ 6.0.0 with the Processing 4.5.6 core library loaded.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click SetupDrawSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
A blank 500 x 350 sketch window opens.

STUDENT TASK:
Keep this working wrapper. During the lesson, add drawing commands to setup()
and draw() at the three checkpoints.
