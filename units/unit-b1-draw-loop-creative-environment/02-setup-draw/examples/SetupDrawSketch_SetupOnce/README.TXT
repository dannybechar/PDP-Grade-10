PROJECT TITLE: SetupDrawSketch - Setup Once

PURPOSE:
Checkpoint 1 for B1.1.2. Demonstrate that setup() runs once and that pixels
drawn there remain visible when nothing paints over them.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click SetupDrawSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
One orange 60 x 60 circle appears at the center of a light-gray 500 x 350
canvas. draw() is empty.
