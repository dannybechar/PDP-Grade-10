PROJECT TITLE: Moving Circle Demo

PURPOSE:
Optional teacher preview for B1.1.2. Demonstrate repeated execution plus a
changing value without teaching controlled motion yet.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click MovingCircleDemo.
4. Run void main(String[] args).
5. Accept the argument and click OK.

EXPECTED RESULT:
An orange circle moves one pixel to the right on every frame and eventually
leaves the visible canvas. This is a watch-only preview; motion is taught later.
