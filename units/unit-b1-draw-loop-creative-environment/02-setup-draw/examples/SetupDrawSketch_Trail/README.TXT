PROJECT TITLE: SetupDrawSketch - Trail

PURPOSE:
Checkpoint 2 for B1.1.2. Make repeated calls to draw() visible without
introducing velocity or edge logic.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click SetupDrawSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.
6. Move the pointer slowly inside the sketch window.

EXPECTED RESULT:
Orange circles accumulate into a trail. background(220) runs once in setup(),
so earlier circles are not cleared.
