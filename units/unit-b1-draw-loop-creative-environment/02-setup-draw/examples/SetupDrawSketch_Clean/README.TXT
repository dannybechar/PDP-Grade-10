PROJECT TITLE: SetupDrawSketch - Clean Follower

PURPOSE:
Checkpoint 3 and final target for B1.1.2. Show how repainting the background at
the start of every frame removes the previous circle.

HOW TO RUN:
1. Open this folder as a BlueJ project.
2. Click Compile.
3. Right-click SetupDrawSketch.
4. Run void main(String[] args).
5. Accept the argument and click OK.
6. Move the pointer inside the sketch window.

EXPECTED RESULT:
One orange circle follows the pointer without leaving a trail. background(220)
is the first line in draw().
