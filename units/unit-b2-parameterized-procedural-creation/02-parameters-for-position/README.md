# B2.1.2 — Parameters for Position

This lesson teaches students to replace hardcoded centres with x and y parameters and preserve component offsets.

## Materials

- [`teacher/B2.1.2_Parameters_for_Position_Revised.pptx`](teacher/B2.1.2_Parameters_for_Position_Revised.pptx): revised 45-minute presentation with timed notes, prediction prompts, misconceptions, and recovery guidance.
- [`examples`](examples): three runnable BlueJ projects synchronized with the lesson.

## Projects

| Project | Expected result |
|---|---|
| `PositionSketch_Fixed` | One fixed flower centered at (200, 200). |
| `PositionSketch_Multiple` | Three identical flowers at three supplied centres. |
| `PositionSketch_BalloonComplete` | Three balloons; each string preserves its offset from the supplied centre. |

## Run a project

1. Open the project folder in BlueJ.
2. Compile `PositionSketch`.
3. Right-click the class tile and run `void main(String[] args)`.
4. Compare the result with the project README and lesson checkpoint.
