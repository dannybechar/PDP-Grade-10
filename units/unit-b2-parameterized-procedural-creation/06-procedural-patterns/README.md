# B2.2.3 — Procedural Patterns

This lesson teaches students to use loop variables in a traceable property rule to turn a uniform grid into a pattern.

## Materials

- [`teacher/B2.2.3_Procedural_Patterns_Revised.pptx`](teacher/B2.2.3_Procedural_Patterns_Revised.pptx): revised 45-minute presentation with timed notes, prediction prompts, misconceptions, and recovery guidance.
- [`examples`](examples): three runnable BlueJ projects synchronized with the lesson.

## Projects

| Project | Expected result |
|---|---|
| `PatternSketch_Uniform` | A uniform 4 × 4 grid. |
| `PatternSketch_RowGrowth` | Shapes grow predictably from row to row. |
| `PatternSketch_Complete` | Size follows a rule using both row and column. |

## Run a project

1. Open the project folder in BlueJ.
2. Compile `PatternSketch`.
3. Right-click the class tile and run `void main(String[] args)`.
4. Compare the result with the project README and lesson checkpoint.
