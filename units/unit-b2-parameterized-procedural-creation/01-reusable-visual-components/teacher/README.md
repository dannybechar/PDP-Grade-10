# Teacher materials

Open `B2.1.1_Reusable_Visual_Components_Revised.pptx` in PowerPoint and use Presenter View for timing, expected responses, misconceptions, and recovery guidance.

The timed sequence on slides 1–15 totals 45 minutes. Slides 16–18 are untimed appendices.

Before class:

1. Confirm BlueJ reports `core-4.5.6.jar` as `(Loaded)`.
2. Compile all five projects in `../examples`.
3. Run the inline and packaged flower projects and compare them.
4. Keep `ComponentSketch_DoubleCall` closed until students commit to a prediction.
5. Keep `ComponentSketch_BalloonComplete` closed unless students need recovery support.
