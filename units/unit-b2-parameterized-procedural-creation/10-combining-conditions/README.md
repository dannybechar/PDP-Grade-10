# B2.4.2 — Combining Conditions

This lesson teaches students to combine a helper function, loop, controlled random value, and condition while keeping each responsibility traceable.

## Materials

- [`teacher/B2.4.2_Combining_Conditions_Revised.pptx`](teacher/B2.4.2_Combining_Conditions_Revised.pptx): revised 45-minute presentation with timed notes, prediction prompts, misconceptions, and recovery guidance.
- [`examples`](examples): three runnable BlueJ projects synchronized with the lesson.

## Projects

| Project | Expected result |
|---|---|
| `CombinedSketch_Function` | Three calls demonstrate the condition inside the helper function. |
| `CombinedSketch_Loop` | A loop supplies positions and values to the same conditional helper. |
| `CombinedSketch_Complete` | Eight stable markers: loop controls count/x, random supplies y/value, and the helper condition chooses appearance. |

## Run a project

1. Open the project folder in BlueJ.
2. Compile `CombinedSketch`.
3. Right-click the class tile and run `void main(String[] args)`.
4. Compare the result with the project README and lesson checkpoint.
