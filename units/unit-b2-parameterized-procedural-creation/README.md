# Unit B2 — Parameterized & Procedural Creation

Unit B2 develops reusable visual procedures from the drawing, state, tracing, and modification skills established in Unit B1.

## Contents

- [`01-reusable-visual-components`](01-reusable-visual-components): package a fixed multi-shape drawing sequence into a named no-parameter method, call it from `draw()`, and verify that refactoring preserves the visible result.
- [`02-parameters-for-position`](02-parameters-for-position): replace fixed centres with `x` and `y` parameters while preserving component offsets.
- [`03-combining-parameterized-properties`](03-combining-parameterized-properties): combine position and size parameters in one reusable component.
- [`04-repeated-structures`](04-repeated-structures): replace manual repeated calls with a counted loop.
- [`05-nested-loops-grids`](05-nested-loops-grids): nest row and column loops to generate grids.
- [`06-procedural-patterns`](06-procedural-patterns): use loop variables in traceable rules that vary repeated shapes.
- [`07-controlled-randomness`](07-controlled-randomness): choose random position, size, and shade within deliberate bounds.
- [`08-regenerate-compare`](08-regenerate-compare): rerun the same algorithm and distinguish fixed structure from regenerated values.
- [`09-conditions-appearance`](09-conditions-appearance): use a condition to vary generated appearance from position or loop state.
- [`10-combining-conditions`](10-combining-conditions): combine functions, loops, controlled randomness, and conditions.

Each lesson includes a revised presentation with teacher notes and synchronized runnable BlueJ
projects.
