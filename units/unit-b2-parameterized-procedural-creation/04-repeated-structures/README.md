# B2.2.1 — Repeated Structures

This lesson teaches students to replace repeated calls with a counted loop and trace the loop variable.

## Materials

- [`teacher/B2.2.1_Repeated_Structures_Revised.pptx`](teacher/B2.2.1_Repeated_Structures_Revised.pptx): revised 45-minute presentation with timed notes, prediction prompts, misconceptions, and recovery guidance.
- [`examples`](examples): three runnable BlueJ projects synchronized with the lesson.

## Projects

| Project | Expected result |
|---|---|
| `LoopSketch_Manual` | Four manually repeated calls. |
| `LoopSketch_Row` | Four shapes generated by i values 0 through 3. |
| `LoopSketch_Complete` | Six evenly spaced shapes whose size also follows i. |

## Run a project

1. Open the project folder in BlueJ.
2. Compile `LoopSketch`.
3. Right-click the class tile and run `void main(String[] args)`.
4. Compare the result with the project README and lesson checkpoint.
