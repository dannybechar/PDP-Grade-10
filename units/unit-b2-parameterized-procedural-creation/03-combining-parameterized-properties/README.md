# B2.1.3 — Combining Parameterized Properties

This lesson teaches students to combine position and size parameters while scaling offsets proportionally.

## Materials

- [`teacher/B2.1.3_Combining_Parameterized_Properties_Revised.pptx`](teacher/B2.1.3_Combining_Parameterized_Properties_Revised.pptx): revised 45-minute presentation with timed notes, prediction prompts, misconceptions, and recovery guidance.
- [`examples`](examples): three runnable BlueJ projects synchronized with the lesson.

## Projects

| Project | Expected result |
|---|---|
| `PropertySketch_PositionOnly` | A position-configurable flower with fixed size. |
| `PropertySketch_Garden` | Five flowers with independent positions and sizes. |
| `PropertySketch_BalloonComplete` | Three proportionally scaled balloons at different positions. |

## Run a project

1. Open the project folder in BlueJ.
2. Compile `PropertySketch`.
3. Right-click the class tile and run `void main(String[] args)`.
4. Compare the result with the project README and lesson checkpoint.
