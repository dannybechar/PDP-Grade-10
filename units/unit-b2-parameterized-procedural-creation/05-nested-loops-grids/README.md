# B2.2.2 — Nested Loops & Grids

This lesson teaches students to nest a column loop inside a row loop and predict total shapes as rows times columns.

## Materials

- [`teacher/B2.2.2_Nested_Loops_Grids_Revised.pptx`](teacher/B2.2.2_Nested_Loops_Grids_Revised.pptx): revised 45-minute presentation with timed notes, prediction prompts, misconceptions, and recovery guidance.
- [`examples`](examples): three runnable BlueJ projects synchronized with the lesson.

## Projects

| Project | Expected result |
|---|---|
| `GridSketch_Row` | One row generated by one loop. |
| `GridSketch_ThreeByThree` | A 3 × 3 grid; the inner loop completes each row. |
| `GridSketch_Complete` | A 4 × 6 grid containing 24 shapes. |

## Run a project

1. Open the project folder in BlueJ.
2. Compile `GridSketch`.
3. Right-click the class tile and run `void main(String[] args)`.
4. Compare the result with the project README and lesson checkpoint.
