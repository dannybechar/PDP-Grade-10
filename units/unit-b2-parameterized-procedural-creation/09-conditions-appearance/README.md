# B2.4.1 — Conditions & Appearance

This lesson teaches students to use one condition to vary a generated shape’s appearance from a position or loop-counter threshold.

## Materials

- [`teacher/B2.4.1_Conditions_Appearance_Revised.pptx`](teacher/B2.4.1_Conditions_Appearance_Revised.pptx): revised 45-minute presentation with timed notes, prediction prompts, misconceptions, and recovery guidance.
- [`examples`](examples): three runnable BlueJ projects synchronized with the lesson.

## Projects

| Project | Expected result |
|---|---|
| `ConditionSketch_Position` | Six circles; fill changes at the x = 220 threshold. |
| `ConditionSketch_Counter` | Indices 0–2 use one fill; indices 3–5 use another. |
| `ConditionSketch_Complete` | Alternating size and shade determined by an even/odd condition. |

## Run a project

1. Open the project folder in BlueJ.
2. Compile `ConditionSketch`.
3. Right-click the class tile and run `void main(String[] args)`.
4. Compare the result with the project README and lesson checkpoint.
