# B2.3.1 — Controlled Randomness

This lesson teaches students to generate random values once inside chosen bounds so the result remains stable for inspection.

## Materials

- [`teacher/B2.3.1_Controlled_Randomness_Revised.pptx`](teacher/B2.3.1_Controlled_Randomness_Revised.pptx): revised 45-minute presentation with timed notes, prediction prompts, misconceptions, and recovery guidance.
- [`examples`](examples): three runnable BlueJ projects synchronized with the lesson.

## Projects

| Project | Expected result |
|---|---|
| `RandomSketch_Position` | Six fixed-size circles at random in-bounds centres; each run creates a new arrangement. |
| `RandomSketch_SizeShade` | Eight circles with controlled position, size, and grayscale ranges. |
| `RandomSketch_Complete` | Ten stable circles constrained to a horizontal band. |

## Run a project

1. Open the project folder in BlueJ.
2. Compile `RandomSketch`.
3. Right-click the class tile and run `void main(String[] args)`.
4. Compare the result with the project README and lesson checkpoint.
