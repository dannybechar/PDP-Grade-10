# B2.3.2 — Regenerate & Compare

This lesson teaches students to rerun the same code to distinguish fixed structure from newly sampled random values.

## Materials

- [`teacher/B2.3.2_Regenerate_Compare_Revised.pptx`](teacher/B2.3.2_Regenerate_Compare_Revised.pptx): revised 45-minute presentation with timed notes, prediction prompts, misconceptions, and recovery guidance.
- [`examples`](examples): three runnable BlueJ projects synchronized with the lesson.

## Projects

| Project | Expected result |
|---|---|
| `CompareSketch_Starter` | Six shapes in one stable run; rerunning changes x and size only. |
| `CompareSketch_FixedAndVariable` | Count, x spacing, colour, and bounds stay fixed; y and size vary between runs. |
| `CompareSketch_Complete` | Seven shapes: x and count stay fixed while y, size, and shade regenerate. |

## Run a project

1. Open the project folder in BlueJ.
2. Compile `CompareSketch`.
3. Right-click the class tile and run `void main(String[] args)`.
4. Compare the result with the project README and lesson checkpoint.
