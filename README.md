## Verified example

### FirstSketch

Location: `units/unit-b/00-environment-setup/FirstSketch`

This BlueJ project verifies that Processing is correctly connected to BlueJ.

Expected result: a 400 × 400 dark window containing an orange circle that follows the mouse.

## Verified Windows environment

- Windows 11, 64-bit, x64 processor
- BlueJ 6.0.0
- Processing 4.5.6
- Processing core library loaded successfully in BlueJ
